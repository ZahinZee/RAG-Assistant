# RAG-Assistant

A personal engineering knowledge assistant that uses Retrieval-Augmented Generation (RAG) to answer questions from your documents, with source citations and conversational memory.

## Goals

- Retrieve relevant information from uploaded documents.
- Generate answers grounded in document content, with source references.
- Add persistent conversational memory as a separate capability.
- Learn AI/RAG concepts through a working application.
- Strengthen software engineering fundamentals through incremental implementation.

## Planned technology

- Python 3.12
- FastAPI
- ChromaDB
- Anthropic API
- Git and GitHub

## Development status

**Current stage:** Project setup.

Features will be implemented incrementally, with tests and documentation added as the project grows.

## Learning approach

Each milestone focuses on understanding the design, implementing a small feature, testing its behavior, and documenting what was learned.
